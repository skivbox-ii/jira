# Реестр, приоритет детей и группировка динамики

Дата: 26.09.2026. Статус: реализация и проверка, приёмка ещё не закрыта.

## Объём

- Срок исполнения Excel в реестре: строгий существующий разбор дат,
  сортировка календарных дат, фильтр, сохранение видимости и ширины.
  Пустые и неоднозначные значения не заменяются выдуманной датой.
- Модуль Excel сопоставляется с компонентом; фактические компоненты Jira
  загружаются отдельно от ожидаемого значения. Справочник проверяется
  для выбранного проекта, поздний ответ другого проекта игнорируется.
  Дочерняя задача показывает собственные компоненты, не компоненты истории.
- Перед дозаведением читается текущий приоритет родительской истории.
  После создания новой истории её приоритет читается из Jira перед детьми.
  Ошибка чтения не допускает создания детей с произвольным приоритетом.
- Журнал динамики объединяет события одной задачи, одного идентифицированного
  автора и одной минуты. Подробности раскрываются; завершение зелёное.
  Исходные события, счётчики, LLM-контекст и подробный экспорт не сокращаются.
