## Изменения

- Счётчики, окна метрик, HTML-выгрузка и фиксированный заголовок LLM
  используют подтверждённые итоги. Знаки сравнения убраны. Стрелка,
  похожая на знак «меньше», заменена на Lucide Undo2 с подсказкой.
- Неполная история одной задачи исключает только затронутые замечания
  из итогов истории. Видны покрытие, ключи исключённых замечаний и причины.
  Все наблюдаемые события и просрочка имеют отдельное покрытие.
  Строгие глобальные показатели остаются неизвестными при неполноте.
- Без единого подтверждённого замечания история не показывает ложные нули.
  Готовность отдельной задачи не считается готовностью всего замечания.
- Текущий баланс подписан «на момент загрузки», полный прошедший день
  «на конец дня». Миллисекундные расхождения скрыты в технических подробностях;
  ошибки распознавания сроков названы «Не распознаны сроки».
- Реальное расхождение EVOSCADA-21769: changelog 10:53:04.000Z,
  updated 10:53:03.998Z, всего 2 мс. Допуск теперь проверяет разность меньше
  секунды, а не одинаковый номер секунды. Времена не изменяются;
  разница от 1000 мс остаётся блокирующей. Это уточняет ACT-01.
- Старый снимок не сдвигает общий текущий срез на предыдущий день,
  если есть свежие снимки. Старые данные по-прежнему исключаются.
