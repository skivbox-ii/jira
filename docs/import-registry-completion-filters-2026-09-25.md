# Перенос текста и раздельное исключение готовых: 25.09.2026

## Изменения

- В столбце «Замечание из Excel» сняты все ограничения количества строк:
  текст переносится целиком, включая свёрнутые группы и незаведённые замечания.
- «Исключить готовые» действует только на дочерние задачи. Исходная история
  остаётся видимой, даже если готова сама или все её дочерние задачи скрыты.
- «Исключить готовые истории» скрывает всю группу готовой исходной истории,
  включая незавершённые дочерние задачи. Для незаведённых замечаний старый
  статус из Excel не является основанием скрывать строку.
- Галочки независимы, применяются по ОК. Отмена не меняет фильтр; «Снять
  фильтр» и общий сброс очищают обе. Индикация активна при любой галочке.
- Точные фильтры значений и показ родителя для контекста сохранены.
  Список статусов не сокращается из-за этих двух галочек; остальные списки
  учитывают скрытые группы. Запись в Jira не добавлялась и не менялась.
