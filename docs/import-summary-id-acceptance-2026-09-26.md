# REG-04: ID журнала из темы истории

## Результат

Выполнено 26.09.2026. Код опубликован в `8cb09d0`.
При отсутствии исходного ID используется числовой префикс темы связанной
родительской истории. Заполненный ID, включая числовой ноль, сохраняется.
Дочерние задачи используют ID родительской группы, а не собственные темы.
Запись в Jira и изменение исходных столбцов не выполняются.

Поддержаны `2650. Тема`, `2795.Линия`, `№42. Тема`, `#42 Тема`, `42 Тема`
и тема из одного номера. Номер внутри текста, даты и дробные числа не
распознаются как ID. Для связанной истории «Динамика» использует этот же
результат; при отсутствии номера её резервный идентификатор остаётся ключом Jira.
