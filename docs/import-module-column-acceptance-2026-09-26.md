# Колонка «Модуль» в динамике

## Объём ACT-06

Отдельная видимая колонка после «Тикет · Роль». Источник: текущие компоненты
исходной истории Jira. Компоненты ребёнка не подменяют модуль замечания.
Все названия показаны полностью, отдельными строками. Пустой набор обозначен
«Без компонента», отсутствующие данные обозначены «Компоненты неизвестны».

Фильтр предлагает отдельные компоненты с поиском и мультивыбором; совпадения
объединяются по ИЛИ. Это фильтр журнала, он не меняет общий срез и LLM.
Сортировка по русскому алфавиту перемещает целые группы замечаний.
Ширина, порядок, видимость и фильтр сохраняются в пользовательской раскладке.
Старые раскладки получают видимый модуль без сброса остальных настроек;
последующее явное скрытие сохраняется. HTML включает те же значения и порядок.
