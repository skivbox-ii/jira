# Pico: приёмка чата подготовки задач, 03.11.2026

## Объём

Основной экран помощника заменён разговором и одной карточкой задачи.
Существующие поля Jira, настройки, вложения и создание сохранены в ручном
редакторе. Pico использует Pi Core/Pi AI 1.4.0, включённые в AMD-сборку,
и прежний shared LLM transport. Новых провайдеров или серверов нет.

Реализованы семь инструментов: чтение задачи и шаблона, схема полей,
поиск значений, проверенный patch, предложение изменения шаблона и
проверка готовности. Инструмента создания тикета нет. Сохранение шаблона
и замена ручных значений требуют явного применения; создание — кнопки.

Разговор хранится отдельно от задачи в области origin/user/project/draft.
Восстановление не запускает модель и не повторяет инструменты. Старый
черновик сохраняется как карточка. Ручная правка или смена области
отменяет устаревшую обработку. Последняя автоматическая правка доступна
для отмены только при совпадении ревизии.

## Личная локальная проверка

Через браузерное управление лично проверены описание задачи, уточнение,
обновление той же карточки, открытие ручного редактора, ручная тема,
предложение AI с сохранением ручного значения, отклонение замены и просмотр
точного шаблона. Компонент отображается названием «API», а не ID; поповер
токенов показывает отдельно бюджет каждого запроса и оценку последнего хода Pico.

На локальной заглушке выполнено создание DEMO-101, после которого работает
«Новый разговор». На финальной сборке повторно пройдено применение изменения
шаблона: готовность сбрасывается, выполняется переоценка, обязательный вопрос
блокирует создание, ответ возвращает готовность. Служебный запрос переоценки
не добавляется в исходные данные или описание демонстрационной карточки.

На 390 px лично осмотрены карточка, её действия и полноэкранный ручной
редактор с доступным закрытием; горизонтального переполнения не наблюдалось.
После проверки возвращён обычный размер браузера. Рабочий локальный preview:
`http://127.0.0.1:4321/`.

Все данные локального preview синтетические. Транспорт выдаёт подготовленные
ответы, а инструменты и Pi выполняются настоящие. Эти проверки подтверждают
поведение приложения; качество извлечения фактов живой моделью ими не принято.

## Ограничения

- Прод-приёмка новой версии в Citrix не выполнена. Реальные тикеты не создавались.
- Токены оцениваются консервативной эвристикой, а не токенизатором провайдера.
  Резерв проверяется локально после ответа и не ограничивает генерацию сервиса.
- При нехватке контекста старые завершённые ходы явно исключаются только
  из запроса; сохранённая переписка остаётся полной. Если текущий ход и
  актуальная карточка не помещаются, обработка останавливается.
- Разговор ограничен 8 запросами модели, 12 вызовами инструментов и 180 секундами
  на ход. Нет автоматических бесконечных повторов.
- Поиск значений использует загруженные каталоги Jira; неполнота обозначается
  явно. Исполнитель, оценки, Epic и Sprint остаются ручными полями.
- Web Locks усиливают защиту одновременного создания из вкладок при наличии
  API браузера. Без них остаётся прежняя защита через durable guards и
  localStorage CAS; она не является атомарным межвкладочным mutex.
- Шаблоны персональные, не распространяются автоматически коллегам.

## Независимое ревью

Работа выполнена Sol 6.1 Author/Reviewer. Ревью runtime принято без замечаний.
В ревью логики найдены и исправлены три дефекта: влияние ошибки истории на
защиту создания, поздний результат применения шаблона в другой области и
готовность без новой смысловой оценки. Повторное ревью: 11 целевых тестов
и три дополнительных прогона настоящего Pi на scripted transport, замечаний нет.

Финальное ревью выявило четыре недочёта: восстановление начальной загрузки Jira,
названия значений каталогов, понятные безопасные причины ошибок и статистика
именно Pico. Все исправлены; повторное независимое ревью принято,
14 целевых проверок пройдено. Изменения reviewed domain сохранены.

Покрывающие проверки автора после исправлений: UI 93/93, логика 126/126.
Это не заменяет общий итоговый прогон и не является приёмкой живой модели.
