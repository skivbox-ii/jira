# Компактный управленческий отчёт, 27.09.2026

## Область AI-03

В существующем окне «LLM-отчёт» появился общий отчёт за семь календарных
дней до выбранной даты включительно и компактный режим одного дня.
Числа рассчитывает код по загруженному срезу проекта/Epic/компонентов.
LLM получает эти числа и ограниченную выборку примеров, а не весь changelog.

- Один запрос на явное формирование отчёта либо вопрос. Нет фоновой
  генерации, map/reduce, дополнительных вызовов для сжатия и автоповторов.
- Контекст отчёта: до 15000 UTF-8 байт. Вопрос с контекстом: до 18000;
  инструкции: до 4000. Размер и сокращения видны перед отправкой.
- Детали не более десяти замечаний, приоритет: просрочка, возвраты,
  открытые без переходов, готовность, новые. Если лимит не позволяет
  включить десять, фактическое число показано. Итоги считают весь срез.
- Вопросы используют неизменяемый снимок отчёта. Непоместившиеся реплики
  диалога явно учитываются как пропущенные. Длинный вопрос отклоняется
  до транспорта. Новые данные помечают старый ответ как устаревший.
- Закрытие дочерней задачи не означает готовность замечания. Переход
  полной готовности за период не означает, что замечание осталось готовым.
- Отсутствие создания/смены статуса/назначения не называется отсутствием
  работы. Изменения описания остаются в счётчике событий, но их полные
  версии не передаются. Нераспознанные сроки не становятся нулевым риском.
- Worklog ограничен периодом и дедуплицирован по задаче/ID записи.
  Накопленные часы снимка отделены от часов за период. Команды и роли
  обозначены как текущие; выводов о загрузке людей по отсутствию worklog нет.

## Реализация

Новый чистый модуль `activity-brief.js`, адаптер в `activity-ui.js`,
существующий диалог `activity-ai-ui.js`, его стили и регистрация сборки.
Транспорт использует только сохранённое подключение LLM.

В `llm-client.js` добавлен необязательный `allowProtocolFallback:false`:
иначе ответ HTTP 404/405 мог незаметно вызвать второй запрос.
Значение по умолчанию не меняет поведение других вызовов. Синхронизированы
только соответствующие встроенные копии: importer, Timesheet runtime,
User Activity bundle/runtime. В двух других виджетах разница ровно в
одной строке общего клиента, без изменений их поведения.

## Ограничения

Качество ответа рабочего провайдера не проверяется живым вызовом агента:
он оставлен явному действию пользователя. Проверка в Citrix ограничена
подготовкой и просмотром, без генерации и без записей Jira. Проблемы
с исходными сроками/колонками Excel этим пунктом не закрываются.
