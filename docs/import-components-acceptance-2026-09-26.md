# Компоненты и читаемая динамика: приёмка и ревью

## Объём

COMP-01, ACT-04, ACT-05. Синхронизация только компонентов родительских
историй из Excel, с предварительным просмотром, выбором и явным подтверждением.
Общий срез динамики по текущим компонентам историй применяется к сводкам,
переходам, журналу, HTML и LLM. В минутных группах сразу видны действия.

Экранная форма берётся только из явных полей журнала или импортной таблицы
описания. Название формы не угадывается по теме задачи или компоненту.

## Второй цикл

Независимое ревью и личный просмотр выявили следующие проблемы; все
исправлены с регрессиями либо повторным визуальным просмотром:

1. Фильтрация отдельных Excel-строк теряла детей повторяющейся истории.
   Теперь выбирается вся группа исходной истории, компоненты объединяются.
2. Счётчик в меню и выбранный отчёт могли использовать разные времена.
   Теперь выбранный срез ограничен точным временем полного отчёта.
3. Явные экранные формы последующих строк терялись. Чтение стало построчным.
4. Кеш мог сохранять вчерашнюю дату просрочки после полуночи МСК.
   При смене текущего дня локальная перерисовка пересчитывает отчёт.
5. Разные исходные модули одного ключа с одинаковым соответствием не
   считались конфликтом. Теперь такое обновление заблокировано.
6. Различающиеся только регистром ключи соответствий выбирали последнее
   значение. Неоднозначное соответствие больше не допускается к записи.
7. После успешной записи реестр сохранял старое отображение компонента.
   По окончании очереди он обновляется один раз вместе со снимками динамики.
8. Пустой набор был без подписи, столбец результата уходил за край на
   обычном экране. Добавлена подпись и уменьшены начальные ширины.
9. Маркер раскрытия занимал отдельную строку. Он перенесён к первому действию.

Синтетический замер jsdom: 100 групп, 600 событий. До изменения раскрытие
занимало 172 мс и вызывало summarize повторно, соседние узлы пересоздавались.
После: 3 мс, 0 повторных summarize, соседние узлы сохранены. Первый рендер
остаётся около 230–250 мс. Это не измерение сетевой задержки или Citrix.
