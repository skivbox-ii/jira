## Ограничения

Jira читается последовательно, не транзакционно. Конец чтения не означает
атомарный срез всех задач: возможна запись после финальной проверки либо
правка комментария за пределами финальной видимой страницы без изменения
Jira.updated. Это явно отражено в контексте. Старые удалённые связи,
комментарии и их прежние редакции не восстанавливаются. Неполные worklog
помечаются отдельно и не подменяются оценками.

Качество живого ответа рабочего провайдера агент не проверяет: только
пользователь запускает генерацию. Постоянная история диалога и вопросы
по этому новому разбору не входят в AI-04.
