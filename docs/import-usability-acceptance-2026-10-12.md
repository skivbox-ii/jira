## LOAD-01

Реализована панель для загрузки реестра, обогащения Excel из Jira и истории
Динамики. Для каждого фактического запроса видны этап, тикет или пакет,
смещение, запрошенное и полученное количество, состояние и время.
Есть остановка, новый запуск и повтор ошибки. Реестр повторяется целиком
ради атомарного снимка; история повторяет только неудачные тикеты.
Ошибки прежнего запуска видны во время повтора и не смешиваются со
счётчиками текущего запуска. Список запросов прокручивается, не обрезается.

Истории запрашиваются по 200, но следующий offset вычисляется по реальному
ответу сервера. Связанные задачи также дочитываются постранично внутри
ограниченных пакетов. Сохраняется существующий предел 1000 исходных историй
с предупреждением. Некорректная, пустая преждевременная или повторная
страница не объявляется успешной. У запросов чтения есть таймаут 30 секунд.

Excel-обогащение готовит строки и экспорт отдельно и публикует их вместе
после успешной обработки книги. Ошибка, остановка и поздний ответ не
заменяют прежний снимок частичными данными. Остановка не управляет
реальными операциями записи. История сохраняет предел трёх одновременных
чтений; страницы комментариев и неполнота остаются явными.

## История Динамики

По исходному коду реестр читает страницы историй и затем связанные задачи.
Динамика дополнительно читает историю изменений каждого уникального
тикета, включая детей, с ограничением в три одновременных запроса.
При неполных комментариях запрашиваются все доступные страницы.
Поэтому число запросов истории может значительно превышать число
замечаний. Реальное соотношение для пользовательского набора здесь
не измерялось.

История нужна для восстановления состояния в выбранный день, переходов,
возвратов, смен исполнителя и событий комментариев. Текущий статус сам
по себе этого не даёт. Есть потенциальные источники лишнего чтения:
повторная загрузка при входе в Динамику, строгая актуальность сегодняшнего
снимка и общий широкий набор полей, включая описание и worklog.
Их изменение не включено в согласованный объём этого цикла.
