# Проверка колонок Excel перед импортом

Короткий дизайн подтверждён пользователем 26.09 ответом «дв» на запрос
подтверждения. EXCEL-02 в работе; повторное согласование не требуется.

## Поведение

После чтения книги проверить лист, заголовок и все десять полей импортера.
Если соответствия точные и однозначные, сохранить быстрый импорт. При
отсутствии/неоднозначности колонок или полностью пустом сопоставленном поле
открыть окно до замены текущего реестра. Пустая найденная колонка отличается
от отсутствующей. Прежние данные и настройки сохраняются при отмене/ошибке.

Таблица: поле импортера, фактическая колонка Excel (буква и заголовок),
примеры значений, результат проверки. Выбор колонки через доступный
всплывающий список с поиском, без native select. Дубли заголовков различаются
буквой и порядковым номером одинакового заголовка. Название замечания
обязательно; остальные поля можно явно пропустить. Не угадывать человека,
компонент или дату по другому полю. Один физический столбец нельзя назначать
нескольким семантическим полям.

Показать файл, выбранный лист и строку заголовков, число замечаний всего,
видимых и скрытых. Разрешить исправить лист/строку заголовков. Существующее
правило исключения скрытых строк не меняется. «Применить и загрузить»
проверяет выбор и импортирует книгу; «Отмена» оставляет прежний реестр.
«Запомнить соответствия» по умолчанию включена, хранение по пользователю.
Настройки без галочки действуют для текущей книги, но не сохраняются.

Сохранённые привязки проверяются заново на каждом файле. Явно пропущенное
поле не должно случайно заполниться через старый alias/fallback. Обновление
настроек не должно уничтожать существующие сопоставления модулей, ролей,
приоритетов и LLM. Никаких записей в Jira на этапе проверки/подтверждения.

## Технический подход

Parser предоставляет inspectWorkbook с физическими индексами колонок,
статусами полей и счётчиками. parseWorkbook использует тот же механизм
выбора заголовка и явные columnBindings. Привязка хранит заголовок и
occurrence, null означает явный пропуск. Отдельный UI-модуль строит диалог;
main хранит pendingImport и атомарно применяет успешный результат.
Защита sequence token от позднего завершения предыдущего чтения файла.

## Проверки

TDD: отсутствующие/переименованные/повторные заголовки, пустые столбцы,
другой лист, заголовок ниже первой строки, скрытые строки, обязательное
поле, пропуск, конфликт привязок, сохранение и отмена. Личный браузерный
прогон desktop/mobile, независимое ревью, полный набор тестов. Публикация
обычным процессом importer; Citrix только чтение файла, проверка окна и
локальный импорт, без создания и обновления Jira.
