# EXCEL-02: подтверждение каждого импорта Excel

Уточнение от 16 ноября 2026 года к [приёмке 27 сентября](import-column-preflight-acceptance-2026-09-27.md). Проверка в Citrix остаётся за пользователем.

При выборе файла открывается «Соответствие колонок Excel». До «Применить и загрузить» прежний реестр остаётся на месте. Галочка «Запомнить соответствия» по-прежнему сохраняет ручные решения; отмена не записывает черновик. Сохранённый выбор используется как начальное значение следующего диалога.

Импортер ищет заголовки по названиям полей и их вариантам, учитывает видимость и наличие данных ниже. Предлагает лист и физический номер строки Excel, которые можно исправить. Для нестандартных заголовков показывает заполненную строку, чтобы пользователь мог назначить поля вручную. Ручной номер строки проверяется по заголовкам при следующей загрузке: он не должен указывать на строки данных из-за вставленной строки сверху.

Ненайденные и неоднозначные поля остаются в режиме «Не импортировать», красным показана причина. Импорт принимает видимые строки с номером **или** текстом замечания, не придумывает отсутствующий текст и не создаёт задачи Jira. В счётчик скрытых попадают строки с тем же критерием, но не в реестр.

## Что проверено локально

- Воспроизведение на прежней сборке: файл со всеми десятью известными заголовками сразу заменял реестр, окно не открывалось.
- Chromium, 1440×900 и 390×844, реальные байты тестовых XLSX: файл с обложкой и полным набором колонок; повторное открытие после перезагрузки страницы; ручное назначение, сохранённый пропуск и отмена. В другой книге выбран лист «Журнал», заголовок «№» в строке 4: в реестр попали оба номера (245, 298) без текста. На книге с двумя одинаковыми заголовками сохранился ручной выбор второй таблицы.
- Отдельная ручная проверка в локальном браузере: у 71 замечания отсутствовал спринт и неоднозначно определялся срок. Нажатие «Применить и загрузить» без назначения этих полей вывело «1–50 из 71».
- При ревью обнаружены два случая потери отображаемых значений. При переходе на соседний лист автоматически найденные колонки теперь определяются заново; ручные назначения и явные пропуски сохраняются. Нестандартный номер из выбранной колонки ID, в том числе «Секция 320», виден в реестре и без текста замечания.
- Номер достаточен для загрузки Excel. Если затем пользователь отдельно открывает создание Story и пытается подтвердить пустое название, форма предлагает его заполнить до обращения к Jira.
- Повторяемый сценарий: `tests/browser/import-file-mapping-acceptance.cjs`; тестовые данные создаются локально, запросы вне стенда заблокированы.

## Проверка в Citrix

Открыть свой Excel, проверить предложенные лист и номер строки. Применить, затем открыть тот же файл ещё раз: окно должно появиться с сохранёнными ручными решениями. На файле с номерами и отсутствующим необязательным полем проверить красный пропуск и число загруженных замечаний. Создание и изменение задач для этой проверки не требуется.
