# REG-07: сроки и раскладки Excel/Jira

## Согласованный объём

29.09 пользователь выбрал вариант с двумя колонками. «Срок Excel» берётся
только из исходных колонок файла с учётом настройки сопоставления.
«Срок Jira» берётся из `fields.duedate` соответствующей истории или ребёнка;
родительский Jira-срок детям не подставляется. Обе колонки доступны в меню,
по умолчанию виден срок активного источника. Даты до текущего дня МСК
красные и жирные, сегодняшняя дата не просрочена до конца дня.
Пустые и невалидные даты не угадываются и не подсвечиваются как просрочка.

Видимость, порядок и ширины колонок сохраняются отдельно для Excel и Jira
в пользовательском `gridLayout.columnLayouts`. Старые настройки служат
основой обоих профилей; нужная колонка срока становится видимой, другой
срок доступен через меню. Остальные предпочтения сохраняются.
Фильтры и сортировка остаются общими. Сброс колонок меняет только текущий
режим; настройки «Динамики» не затрагиваются.

## Реализация

- `api.js`: `duedate` включён в существующие чтения задач, без отдельного
  запроса на каждую строку.
- `main.js`, `registry.js`: отдельный фактический срок каждой Jira-задачи,
  строгая проверка даты, сравнение с текущим календарным днём МСК.
- `grid.js`, `rendering.js`, CSS: две явные колонки, подсветка, отдельные
  профили с миграцией, сохранение общих фильтров, изоляция сброса,
  остановка таймера при уходе в «Динамику» или замене renderer.
- Профильные enrichment/registry/grid тесты и личный сценарий
  `tests/browser/import-deadline-layout-acceptance.cjs`.
- Пересобраны только JS/runtime импортера.

Срок Jira, как и остальные поля реестра, отражает последнее чтение Jira.
После создания или отдельной синхронизации сроков следующее чтение Jira
обновляет колонку; существующие сценарии записи этой задачей не изменены.
Подсветка учитывает текущий день, а не выбранный день отчёта «Динамики».
Один таймер на границу дня МСК обновляет классы существующих ячеек,
не перерисовывая таблицу. Возврат фокуса/видимости проверяет дату после
сна; уход в «Динамику» или замена renderer сразу снимает таймер и слушатели.
