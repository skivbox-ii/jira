# SUM-01: четыре итога по историям

## Изменение

В первом экране «Сводки замечаний» теперь Исправлено / На тестировании /
Снято / В работе. История считается один раз по исходному статусу Jira,
независимо от дочерних задач и фильтра реестра. В работе включает остальные
незавершённые статусы, точные названия и числа приведены под итогом.
Отсутствующие/противоречивые статусы и незаведённые Excel-строки не подменяют
одну из четырёх известных групп. Подробности по всем тикетам, направлениям,
командам, ролям и служебные счётчики сохранены под раскрытием.
