# REG-08: отслеживаемые замечания и дерево внутри ID

## Объём

Подтверждено пользователем 12.10: убрать отдельную колонку раскрытия,
поместить стрелку и звёздочку под ID. Ручное раскрытие временно показывает
всех детей только выбранного замечания. Другие замечания остаются под
фильтром. Любое применение фильтра через «ОК», даже без изменения,
и сброс фильтров возвращают обычный отбор. Массовое раскрытие по-прежнему
показывает только подходящие задачи.

В ID-фильтре добавлены «Все», «Только отслеживаемые», «Без отслеживаемых».
Режим применяется по «ОК», отменяется по «Отмена»/Escape и пересекается
с другими фильтрами. Сброс фильтров сохраняет звёздочки.

## Реализация

- `grid.js`: кнопки под ID, отдельное временное состояние раскрытия,
  сохранение отслеживания по пользователю и проекту, общие отметки
  Excel/Jira, режим фильтра и доступ к нему при скрытом ID.
- Отметка хранит связанные идентификаторы замечания и Jira. При появлении
  ключа Jira он связывается с ранее отмеченным Excel ID; снятие отметки
  удаляет всю такую запись. Номер строки не используется. Отсутствующие
  в новом импорте отметки не удаляются. Без ID и ключа Jira звёздочка
  недоступна с подсказкой, чтобы не смешивать разные безымянные строки.
- `registry.js`: состав группы определяется до ручного раскрытия;
  исключение действует только на дочерние строки выбранной группы.
- `icons.js`, CSS: существующий стиль кнопок, пустая/залитая звезда,
  стабильные размеры 22x24 под ID. Массовая кнопка заголовка перенесена
  в существующую колонку действий, без новой отдельной колонки.
- Колонки Excel/Jira, общие фильтры и сортировка сохранены. При скрытом
  ID кнопки находятся в первой видимой колонке замечания, либо в первой
  видимой колонке, если все колонки замечания скрыты.
- На личной проверке обнаружен выход ID-попапа за нижнюю границу малого
  экрана. Исправлены ограничение viewport и прокрутка списка при видимых
  кнопках применения и отмены. Остальные таблицы не перерабатывались.
