# SUM-01: отработанные истории внедрения

## Согласованное правило

29.09 пользователь подтвердил: «Да, по исполнителю истории».
Незакрытая исходная история с исполнителем из настроенной команды
направления «Внедрение» входит в отдельный итог «Отработано (внедрение)».
Это касается и «Выдано», и «Тестирование». Закрытые и снятые остаются
в своих группах. Назначение только дочерней задачи, роль IMP или совпадение
отображаемого имени не являются основанием. Используются идентификаторы Jira.
Неизвестные и противоречивые данные не объявляются отработанными.
Истории без Excel ID считаются по Jira-ключу; дубли не увеличивают итог.
Сводка по-прежнему охватывает все загруженные истории, а не выборку QA.
