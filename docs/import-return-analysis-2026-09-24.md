## Правила отчёта

- Полная готовность: исходная история и все текущие связанные задачи готовы.
- Повторное открытие замечания: переход из полной готовности к незавершённости.
- Возврат с проверки или тестирования: отдельное движение задачи; показано
  в журнале и матрице, не подменяет показатель повторного открытия замечаний.
- Категория Jira имеет приоритет над названием статуса. Неизвестный
  промежуточный статус не должен давать уверенный нулевой итог.
- Календарный срок и трудозатраты различаются. Трудозатраты сводки относятся
  к снимкам Jira; неизвестные значения не считаются нулём.
