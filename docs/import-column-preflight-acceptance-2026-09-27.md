## Поведение

- Новый файл сначала проверяется отдельно от текущего реестра. Отмена,
  ошибка чтения/разбора и запоздавший ответ старой загрузки не заменяют данные.
- При несовпадении, дублях или пустой колонке появляется таблица десяти
  полей: поле импортера, буква/заголовок Excel, примеры и результат проверки.
- Можно выбрать лист, строку заголовков и конкретный экземпляр одноимённой
  колонки. Необязательные поля пропускаются только явным выбором.
- Показываются видимые и скрытые замечания. Примеры берутся из видимых
  импортируемых строк; при невыбранном тексте замечания количество неизвестно.
- Подтверждение применяет выбор; галочка управляет сохранением соответствий
  по пользователю. Несохранённые настройки действуют для текущей книги,
  включая реестр, динамику, редактор текста и экспорт.
- Таблица поддерживает поиск и мультивыбор в фильтрах, сортировку, ширину,
  порядок и видимость колонок с отдельными пользовательскими настройками.
- Этап проверки и загрузки Excel не создаёт и не обновляет задачи Jira.

## Ревью

Независимое ревью выявило и проверками воспроизвело утечки пропущенных
полей через старые aliases, неверный выбор временного срока/текста,
повторное обнаружение переименованного заголовка, сохранение исходного
статуса Excel, примеры при неоднозначном тексте и одновременное открытие
двух меню. Исправления сопровождаются регрессионными тестами.

Отдельно проверено, что экспорт изменяет выбранный физический экземпляр
колонки ответственного, не соседний одноимённый столбец; смена файла во
время чтения родительской истории отменяет последующее создание детей.
Повторное независимое ревью исправления физических индексов: замечаний
нет; целевой тест фактического XML пройден самим ревьюером.
