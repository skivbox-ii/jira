# REG-06: уточнение составного фильтра QA

## Объём

Запрос 29.09: тестировать и сразу внедрить ИЛИ из трёх условий:
точный статус тестирования, роль QA с любым статусом, исполнитель из
настроенной команды QA. Учитываются исходные истории и дочерние задачи.
Другие выбранные фильтры пересекаются с этим результатом; они не сбрасываются.

## Причина и изменения

- `teams.js`: прежний ранний возврат QA игнорировал участников и отсекал
  завершённые/неизвестные статусы. Теперь используется объединение трёх
  независимых условий, без изменения `currentWork` и других команд.
- `main.js`: независимое ревью обнаружило потерю `assigneeIdentifiers`
  у только что созданного ребёнка. Сохраняются известные идентификаторы
  существующим `userIdentifiers`; имя само по себе не доказывает членство.
- Обе сборки, unit/grid-тесты, локальный сценарий и контракт таблицы обновлены.

  профильные teams/registry/grid: 126/126.

  main/teams/registry: 70/70. Payload создания не менялся.
- Полный повторный прогон: 1621/1621, без пропусков и падений.
  Лог `/tmp/import-qa-union-verified-20260929.log`.
  Первый прогон до запуска стенда 4317 имел три ECONNREFUSED;
  это была ошибка подготовки окружения, а не успешный прогон.
- Независимое ревью Sol6/medium: замечание об идентификаторах исправлено;
  отдельная независимая перепроверка `main.js` без открытых замечаний.
- Личный повторный Chrome 1440/390 px: 84 дочерние строки QA, 19 прямо подходящих историй,
  три условия, без дублей и чужих детей, И с исполнителем, Excel/Jira,
  сохранение после reload, сброс и 4 страницы до последней строки.
  0 Jira-записей, 0 LLM, 0 ошибок страницы, без переполнения документа.
  Артефакты `/tmp/import-qa-union-personal-final-20260929`, просмотрены
  итоговые снимки desktop/mobile. Проверены реальные pointer-действия,
  сохранённое состояние фильтров и соответствующие строки.
- Первый личный прогон 390 px дал расхождение после Apply. Диагностика
  зафиксировала отсоединение меню во время действий; конкретная заменившая
  его перерисовка не установлена. Сценарий теперь ждёт завершения загрузки,
  прокручивает заголовок до открытия меню и проверяет сохранённые фильтры.
  Шесть повторов worker и финальный личный прогон прошли без DOM-click
  обходов. Самостоятельный дефект pointer-управления не доказан.
